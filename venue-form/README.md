# 課後活動場地借用申請表產生器

單一檔案網頁(`index.html`),填資料後產生 A4 PDF。
- 3 筆以內:1 頁 A4,上下兩聯
- 4~12 筆:2 頁,每聯各一頁(只顯示實際填寫的時段)

## 讓大家產生的 PDF 自動存進「你的」Google 雲端

1. 開 <https://script.google.com> → 新增專案 → 把 `apps-script/Code.gs` 全部貼上。
2. 把第一個 `TOKEN` 改成你自己的通關碼。
3. 右上「部署」→「新增部署」→ 類型選「網頁應用程式」
   - 執行身分:**我**
   - 誰可以存取:**所有人**
   - 第一次會要求授權雲端硬碟權限,同意即可。
4. 複製部署後的網址(`https://script.google.com/macros/s/.../exec`)。
5. 編輯 `index.html`,找到這一行,填入網址和同一組通關碼:
   ```js
   const UPLOAD_URL="https://script.google.com/macros/s/.../exec", UPLOAD_TOKEN="你的通關碼";
   ```
6. 把 `index.html` 放到可公開的網站(例如 GitHub Pages)。
   之後每次有人按「下載 PDF」,檔案會自動存到你雲端的「場地借用單」資料夾。

## 注意
- 通關碼會寫在網頁原始碼裡,只能擋一般人。知道網址的人仍可往你的雲端丟 PDF(接收端只收 `%PDF` 檔、單檔上限約 6MB)。
- PDF 內含姓名與手機,資料夾請不要設成公開。
- 不填 `UPLOAD_URL` 就不會上傳,維持原本只下載。
- 在 claude.ai 的 artifact 裡不能對外連線,所以這個功能只能用在放在自己網站上的版本。
- 這個儲存庫是公開的,**請不要把真實的姓名、電話放進程式碼或紀錄裡再提交**。
